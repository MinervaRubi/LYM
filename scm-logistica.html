Productos PULL en Stock Bajo

Los productos PULL no se reponen de forma automática. Se requiere intervención manual para generar las órdenes de compra.

PUSH
REPOSICIÓN AUTOMÁTICA
0
productos

PUSH: reposición automática al quedar bajo el mínimo. En cuanto una salida de inventario deja el producto por debajo del mínimo, el sistema genera inmediatamente un pedido surtido al proveedor y la entrada correspondiente en almacén.

PULL
BAJO DEMANDA MANUAL
0
productos

PULL: reposición solo bajo pedido. El sistema no genera compras automáticas; únicamente emite alertas de stock bajo para que el administrador o encargado genere manualmente la orden al taller o artesano.
